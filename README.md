# Student Grade Checker 🎓

A simple Python project to calculate student grades based on marks entered by the user. 
It shows a beautiful result card with Grade, Status, and Remarks.

## Features ✨

- **Name Formatting**: Automatically converts name to Title Case `ali khan` → `Ali Khan`
- **Marks Validation**: Checks if marks are between 0 to 100
- **Full Grading System**: A+, A, B, C, D, F
- **Pass/Fail Status**: Automatically shows PASS or FAIL
- **Remarks**: Motivational remarks for each grade
- **Clean Result Card**: Neat and professional output

## Grading Scale 📊

| Marks | Grade | Status | Remarks |
| --- | --- | --- | --- |
| 90 - 100 | A+ | PASS | Outstanding! Excellent Work |
| 80 - 89 | A | PASS | Excellent! Keep it up |
| 70 - 79 | B | PASS | Good Job |
| 60 - 69 | C | PASS | Satisfactory |
| 50 - 59 | D | PASS | Need Improvement |
| 0 - 49 | F | FAIL | Fail - Work Harder |
